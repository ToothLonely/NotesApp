# Splash

> Статус: утверждено пользователем и реализовано.

## Внешний вид и движение

- Фон совпадает с нейтральным фоном приложения и поддерживает системную светлую и тёмную тему.
- В центре используется foreground текущей launcher icon без отдельного текста или branding image.
- Иконка появляется с нулевого масштаба и плавно увеличивается до 100% за 500 мс.
- После короткой паузы иконка приближается к пользователю до 200% за 400 мс и одновременно растворяется.
- После завершения анимации splash полностью удаляется, открывая уже подготовленный основной экран.
- При изменении конфигурации после завершения splash повторно не показывается; при cold/warm start новой Activity показывается снова, при hot start — нет.

## Реализация

Системный starting window использует AndroidX SplashScreen и непрозрачный фон без отдельной Activity. Точная двухфазная анимация выполняется поверх готового Compose UI, поскольку системная enter-анимация не предоставляет приложению управление масштабом. Launcher assets остаются единым источником изображения.
