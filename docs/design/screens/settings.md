# Экран Settings

> Статус: проект для согласования.

## Назначение

Экран показывает независимо загружаемый баланс GigaChat и позволяет немедленно применить и сохранить режим темы и одну из четырёх акцентных палитр.

## Иерархия

1. Top App Bar: «Настройки».
2. Balance card.
3. Секция «Тема приложения».
4. Секция «Цветовая схема».
5. Outlined error button «Сбросить настройки».
6. Bottom Navigation.

## Состояния

Preferences и remote balance загружаются независимо, поэтому экран не заменяется общим spinner без необходимости.

| Состояние | Представление | Действия |
| --- | --- | --- |
| Preferences loading | skeleton theme/palette controls; balance начинает собственную загрузку | Bottom Navigation |
| Content + balance loading | controls активны; balance card показывает compact progress + «Загружаем баланс…» | менять тему/палитру/сбросить |
| Content + balance success | крупное число и label «токенов» | все настройки |
| Content + balance error | error icon, «Не удалось загрузить баланс», supporting text | «Повторить»; локальные настройки остаются активны |
| Preferences error | full/section error «Не удалось загрузить настройки» | «Повторить»; balance card может отображать собственный state |
| Saving preference | выбранное значение применяется optimistic; конкретный control кратко busy | остальные независимые controls доступны |
| Save error | значение возвращается к сохранённому, Snackbar/error text | повторить выбор |
| Reset requested | confirmation dialog поверх текущих настроек; значения ещё не изменены | «Отмена» / «Сбросить» |
| Reset saving | после подтверждения System + Indigo применяются optimistic; reset action кратко busy | остальные controls временно недоступны |
| Reset success | диалог закрывается, System + Indigo остаются выбранными | Snackbar «Настройки сброшены» |
| Reset error | диалог закрывается, возвращаются сохранённые значения | Snackbar «Не удалось сбросить настройки»; повторить действие |

## Theme selector

- Compact: `SingleChoiceSegmentedButtonRow` с «Системная», «Светлая», «Тёмная».
- Выбранный вариант имеет selected semantics, check mark и accent-container, а не только новый цвет.
- Изменение применяется без перезапуска и без ожидания сетевого balance.
- При font scale или ширине, где labels не помещаются, используется вертикальная radio-группа из трёх строк.

## Accent selector

- Четыре preset: Индиго, Бирюза, Малина, Янтарь.
- Каждая цель содержит swatch 48dp, label и touch area минимум 64dp.
- Выбранный preset: двойной outline, check mark контрастного `onPrimary` и selected semantics.
- Акцент обновляет FAB, buttons, checkbox, selected filters, progress и активную навигацию немедленно.
- Перестройка цветовой схемы не окрашивает фотографии, error-цвета или нейтральные поверхности.

## Balance card

- Карточка использует радиус 28dp; segmented selector и reset button имеют форму capsule.
- Заголовок `titleMedium`, значение `headlineMedium`, единица `bodyMedium`.
- Loading сохраняет высоту карточки, чтобы секции ниже не прыгали.
- Error остаётся внутри карточки: сетевой сбой не блокирует локальные настройки.
- Технический текст HTTP/OAuth пользователю не показывается; журналирование относится к реализации, а не дизайну.

## Reset

- Button остаётся прозрачным и не выглядит как primary-действие: capsule, outline 1dp в роли `error`, reset-иконка и текст в `error`. Для pressed/focused применяется лёгкое наложение `errorContainer`, без сплошной красной заливки.
- Сбрасываются только theme mode и accent preset; заметки, задачи, вложения и баланс не изменяются.
- Первое нажатие ничего не меняет и открывает confirmation dialog:
  - заголовок: «Сбросить настройки?»;
  - текст: «Тема станет системной, цветовая схема — „Индиго“. Заметки и задачи не изменятся.»;
  - действия: «Отмена» и «Сбросить»; подтверждающее действие использует роль `error`.
- Только после подтверждения применяются System + Indigo. Результат подтверждается Snackbar «Настройки сброшены».

```text
┌────────────────────────────────┐
│ Сбросить настройки?            │
│                                │
│ Тема станет системной,         │
│ цветовая схема — «Индиго».     │
│ Заметки и задачи не изменятся. │
│                                │
│          [Отмена] [Сбросить]   │

```

## Accessibility и длинный текст

- Баланс читается одной фразой: «Баланс GigaChat: 12 480 токенов».
- Каждая палитра сообщает имя и selected state; цвет не является единственным описанием.
- Переключение темы не сбрасывает focus и не вызывает повторное чтение всего экрана.
- Error card имеет alert semantics, Retry — самостоятельную кнопку.
- Reset button сообщает полное действие, а не полагается только на красный цвет: иконка сброса и текст «Сбросить настройки» остаются видимыми во всех темах.
- При открытии confirmation dialog фокус остаётся внутри него; первым безопасным действием в порядке фокуса является «Отмена». После закрытия фокус возвращается на Reset button.
- На увеличенном шрифте controls перестраиваются вертикально, экран прокручивается, labels не обрезаются.
