# Экран Tasks

> Статус: утверждено.

## Назначение

Экран объединяет просмотр, поиск, фильтрацию, сортировку, изменение статуса, создание, редактирование и удаление задачи. Текстовая задача создаётся и редактируется inline без отдельного экрана или Bottom Sheet. Редактирование и удаление не обязательны по `task.md`, но добавлены как согласованное пользователем расширение управления задачами.

Tasks намеренно остаётся вертикальным списком: checkbox, статус и длинные названия лучше сканируются строками. Переключатель List/Grid относится к Notes.

## Иерархия

1. Top App Bar: «Задачи» и sort.
2. Search field.
3. Status filter chips: «Все», «Активные», «Выполненные».
4. Voice/status panel или inline editor, если активны.
5. Task list либо state content.
6. FAB, открывающий popup menu выбора способа создания.
7. Bottom Navigation.

Search, фильтры и App Bar находятся вне прокручиваемого списка. FAB скрывается при прокрутке вниз и возвращается при прокрутке вверх, как на экране Notes. Это не floating overlay, поэтому элементы списка не уходят под строку поиска.

## Создание

FAB открывает anchored popup menu над кнопкой:

- «Ввести текст» с edit-иконкой;
- «Продиктовать» с mic-иконкой.

Текстовый вариант вставляет `InlineTaskEditor` в начало списка и сразу фокусирует поле с открытой клавиатурой. IME Done или confirm сохраняет непустое после `trim` название. Cancel/Back удаляет несохранённую строку. Пустое значение показывает supporting error и не создаёт задачу.

### Геометрия InlineTaskEditor

- Light и Dark используют одну компоновку, выбранную по тёмному макету: rounded container с вертикальной структурой, а не поле и действия в одну тесную строку.
- Сверху находится широкое однострочное поле на всю доступную ширину, высотой минимум 56dp; при длинном названии текст прокручивается горизонтально внутри поля.
- Ниже расположена отдельная строка действий: круглая Cancel target 48dp слева и круглая Confirm target 48dp справа. Между полем и действиями 8dp, внутренний padding контейнера 12dp.
- Checkbox в режиме создания/редактирования скрыт: статус меняется только после возврата строки в обычное состояние.
- Тема меняет только цветовые роли поля, контейнера и действий; размеры, порядок, отступы и положение элементов совпадают.

## Редактирование

- Trailing overflow задачи открывает действия «Редактировать» и «Удалить»; menu item удаления использует иконку и роль `error`.
- «Редактировать» заменяет только выбранную строку на тот же двухуровневый `InlineTaskEditor` с текущим названием. Остальной список остаётся видимым, но в один момент редактируется не более одной задачи.
- Открытие и закрытие редактора существующей задачи сохраняет текущую позицию списка; прокрутка к началу выполняется только при создании новой задачи.
- Пока открыт любой inline editor, overflow-меню остальных строк disabled и сообщает disabled-состояние через семантику. Checkbox остальных строк остаётся самостоятельным и доступным, если для него не выполняется сохранение статуса.
- Поле сразу получает focus, курсор устанавливается в конец названия; confirm или IME Done сохраняет непустое значение после `trim`.
- Cancel/Back восстанавливает исходную строку без изменений. Пустое название не сохраняется и получает supporting error «Введите название задачи».
- Во время сохранения confirm показывает compact progress, повторные действия этой строки disabled. При ошибке редактор остаётся открытым и показывает понятное сообщение.

## Удаление

- «Удалить» из overflow сначала открывает confirmation dialog; до подтверждения данные не меняются.
- Заголовок: «Удалить задачу?»; текст включает название: «Задача „{title}“ будет удалена.»
- Действия: «Отмена» и «Удалить». Подтверждение использует иконку/текст `error`; dialog и кнопки сохраняют округлую геометрию.
- После успеха строка исчезает автоматически и появляется Snackbar «Задача удалена».
- При ошибке задача остаётся в списке, dialog закрывается и появляется error banner/Snackbar с действием «Повторить».
- Удаление одной задачи не переводит весь экран в отдельный режим и не блокирует checkbox остальных строк.

## Сортировка и статус

- В режиме «Все» статус не влияет на позицию: активные и выполненные задачи образуют единую хронологическую очередь.
- Выбранная сортировка «Сначала новые» или «Сначала старые» использует только дату создания. Редактирование названия и изменение checkbox не перемещают задачу.
- Фильтры «Активные» и «Выполненные» скрывают неподходящий статус, не меняя сохранённые данные и хронологический порядок оставшихся строк.
- Выполненная задача: checked checkbox, зачёркнутый title и `onSurfaceVariant`; opacity контента 0.70, при этом доступность состояния обеспечивается не только прозрачностью.
- Checkbox update optimistic; при ошибке возвращается прошлое состояние и показывается banner/Snackbar с объяснением.

## Состояния

| Состояние | Представление | Действия |
| --- | --- | --- |
| Loading | shell экрана + progress «Загружаем задачи…» | Bottom Navigation |
| Empty | icon, «Задач пока нет», «Добавьте задачу текстом или голосом» | FAB и primary action «Добавить задачу» |
| Content | единая очередь по дате создания | toggle, поиск, filter, sort, create |
| Search/filter empty | «Нет задач по выбранным условиям» | «Сбросить фильтры» |
| Creation menu | anchored menu «Ввести текст» / «Продиктовать» над FAB | выбрать способ или закрыть |
| Inline create | editable row вверху списка | confirm/cancel/IME Done |
| Inline edit | выбранная строка заменена редактором с сохранённым title | confirm/cancel/IME Done |
| Delete confirmation | rounded dialog с названием задачи поверх приглушённого списка | «Отмена» / «Удалить» |
| Delete saving | подтверждающее действие busy, повторное нажатие disabled | дождаться результата |
| Voice recording | status panel, timer, stop/cancel | завершить или отменить запись |
| Voice speech processing | progress + «Распознаём речь…» | отмена, если transport позволяет |
| Voice GigaChat processing | progress + «Формулируем задачу…» | список остаётся видимым с меньшим emphasis |
| Voice error | error panel | «Записать снова» либо «Повторить», если запрос можно безопасно повторить |
| Storage error без content | full error state «Не удалось загрузить задачи» | «Повторить» |
| Mutation error с content | список сохраняется, inline banner/Snackbar | повторить действие |
| Permission denied | mic explanation | «Открыть настройки» при permanent denial |

Во время voice processing FAB и повторный voice-запуск disabled. Список остаётся виден; в макете он приглушён. Bottom Navigation остаётся доступен.

## Task row

- Минимальная высота 64dp, padding 8dp по вертикали и 12dp по горизонтали, радиус 24dp.
- Визуальный checkbox 24dp внутри touch target 48dp.
- Title `bodyLarge` в свёрнутом виде занимает одну строку и завершается ellipsis при переполнении. Если title переполнен, весь контейнер задачи становится кликабельным: нажатие на свободную область раскрывает полный текст, повторное нажатие сворачивает его, а ripple обрезается по rounded shape контейнера. Checkbox и trailing overflow остаются самостоятельными интерактивными элементами и не запускают раскрытие.
- Вся строка не переключает статус случайным tap: статус меняет checkbox, что снижает риск ошибочного завершения. При этом checkbox имеет расширенную touch target.
- Trailing overflow имеет отдельную touch target 48dp и действия «Редактировать» / «Удалить». Tap по свободной области строки не меняет статус и не открывает редактор случайно.

## Accessibility и длинный текст

- Checkbox сообщает «{title}, активная/выполненная» и checked state.
- Зачёркивание не является единственным признаком: state также объявляется TalkBack, checkbox остаётся checked.
- При появлении inline editor фокус переходит в поле один раз; ошибки ввода объявляются polite live region.
- Create/edit mode имеет явное state description. После confirm/cancel фокус возвращается к соответствующей строке или FAB.
- Overflow сообщает название задачи в действиях: «Редактировать задачу {title}», «Удалить задачу {title}».
- Confirmation dialog удерживает focus внутри себя; безопасная «Отмена» идёт первой, а после закрытия focus возвращается к overflow выбранной задачи.
- Filter chips имеют radio/selected semantics и горизонтальный scroll при нехватке ширины.
- Voice timer не объявляется каждую секунду; announcement происходит при смене фазы.
- Popup menu доступно с клавиатуры и закрывается Back/внешним tap.
