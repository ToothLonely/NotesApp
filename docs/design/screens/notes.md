# Экран Notes

> Статус: утверждено.

## Назначение

Экран показывает локально сохранённые заметки, позволяет найти и отсортировать их, переключаться между List и Grid, открыть редактор, создать заметку и удалить заметки в явном отдельном режиме.

## Иерархия

1. Top App Bar: «Заметки», sort, List/Grid toggle, toggle delete mode.
2. Search field.
3. Delete-mode banner, только в режиме удаления.
4. List, Grid либо state content.
5. FAB создания.
6. Bottom Navigation.

## Состояния

| Состояние | Представление | Доступные действия |
| --- | --- | --- |
| Loading | App bar и search остаются на месте; в content-area progress + «Загружаем заметки…» | навигация между разделами |
| Empty | outline-иконка и «Заметок пока нет» | FAB ведёт в Editor |
| Content: List | `LazyColumn` широких карточек, новые/старые согласно выбранной сортировке | поиск, Grid, сортировка, открыть, создать, включить удаление |
| Content: Grid | `LazyVerticalGrid` вертикальных карточек в две колонки | поиск, List, сортировка, открыть, создать, включить удаление |
| Search empty | грустная outline-иконка и «Ничего не найдено» без отображения применённого запроса | очистить запрос крестиком в search field |
| Error без content | error state «Не удалось загрузить заметки» | «Повторить» |
| Content + refresh/write error | существующий список сохраняется, сверху компактный error banner | «Повторить» или закрыть banner |
| Delete mode | top title «Удаление заметок», tonal banner, delete icon на каждой карточке | удалить, закрыть режим, перейти в другую вкладку |

### Delete mode

- Вход — icon button «Включить режим удаления».
- Note card перестаёт быть кликабельной, overflow/другие действия скрыты или disabled.
- Единственное действие карточки — отдельная 48dp delete target с описанием «Удалить заметку “{title}”». В Grid она располагается поверх preview в правом верхнем углу на контрастной круглой подложке.
- FAB скрывается до выхода из режима удаления; Bottom Navigation остаётся доступной.
- При прокрутке списка или сетки вниз FAB создания скрывается движением вниз с затуханием;
  прокрутка вверх возвращает его. Bottom Navigation остаётся неподвижной и доступной.
- Удаление происходит сразу, как требует задание; после успеха показывается Snackbar «Заметка удалена».
- Если удаление не удалось, карточка остаётся в списке и показывается error banner. Режим не закрывается автоматически.
- Выход — close icon, системный Back или переход в другую вкладку.

## List и Grid

- Переключатель находится между sort и delete actions. Иконка показывает доступный переход, а selected container и state description сообщают текущий режим.
- Content description: «Показать заметки сеткой» в List и «Показать заметки списком» в Grid; state description — «Список» или «Сетка».
- На compact width Grid содержит две равные колонки, horizontal/vertical gap 12dp. От 600dp допускаются три колонки с минимальной шириной карточки 180dp.
- View mode не меняет поиск, сортировку или набор данных и сохраняется локально между запусками.
- Scroll position сохраняется отдельно для List и Grid в рамках процесса; после смены режима пользователь попадает к той же ближайшей заметке.

## Note card

- List card: горизонтальная компоновка, высота определяется content, внутренний padding 12dp, форма `extraLarge`; preview 96×80dp.
- Grid card: вертикальная компоновка, форма `extraLarge`; preview занимает ширину карточки с aspect ratio 4:3, текстовый блок имеет padding 12dp.
- Preview использует `ContentScale.Crop`; без изображения — tonal placeholder с outline note icon.
- Заголовок `titleMedium`, максимум две строки.
- Дата создания `bodySmall` в локальном формате; время показывается только если оно нужно для различения близких записей.
- Карточка целиком имеет одну click target и объединённые semantics «{title}, создано {date}».
- Preview декоративный: название заметки уже идентифицирует элемент.

## Поиск и сортировка

- Текущий порядок до появления пользовательского Sort menu — по времени последнего изменения от новых к старым. Созданная или только что сохранённая заметка находится вверху списка.
- Для заметки независимо хранятся дата создания и дата последнего изменения. Редактирование обновляет только дату изменения; дата создания сохраняется.
- Ввод не фильтрует до Search/IME Search.
- После применения запрос остаётся в поле; clear немедленно возвращает полный список.
- Поиск без учёта регистра сначала проверяет точную подстроку, затем fuzzy-совпадение:
  символы запроса должны находиться в том же порядке внутри отдельного слова.
- Fuzzy-поиск применяется к словам запроса длиной от трёх символов; более короткие
  слова требуют точного вхождения, чтобы ограничить случайные результаты.
- Порядок групп: точная подстрока в заголовке, fuzzy в заголовке, точная подстрока
  в тексте, fuzzy в тексте. Заметка показывается только в первой подходящей группе.
- Каждая группа совпадений независимо следует выбранному порядку по времени изменения
  со стабильным `id`-порядком при одинаковом времени.
- Sort menu: «Сначала новые» / «Сначала старые».
- Сортировка применяется и к полному списку, и к результату поиска.

## Accessibility и длинный текст

- sort/delete/close имеют content descriptions и selected/state description, где применимо;
- Grid читается TalkBack построчно слева направо; позиция элемента объявляется после названия только при необходимости;
- в delete mode TalkBack не объявляет карточку как открываемую;
- заголовок до двух строк, дата остаётся видимой; очень длинный текст обрезается ellipsis;
- empty/error content центрируется визуально, но остаётся в естественном focus order после search;
- FAB: «Создать заметку».
